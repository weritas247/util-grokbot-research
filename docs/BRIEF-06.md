# Codex 작업 지시 #6 — 버그 1건

증상: 첫 로드 시 타임라인 20개가 전부 보이고 "이전 업데이트 12개 더 보기" 버튼(#more-updates)은 hidden 상태.
기대(BRIEF-02 9c): 필터·검색이 없을 때는 최신 8개만 보이고 버튼 표시 → 클릭 시 전부 표시 + 버튼 숨김. 월/종류 필터를 고르면 조건에 맞는 전부 표시, "전체"로 돌아오면 다시 8개 + 버튼(펼친 상태였다면 펼친 상태 유지).
제목 옆 개수는 "20개 중 8개 표시"처럼 실제 보이는 수를 반영.
원인을 찾아 assets/js 쪽만 고쳐(기존 포맷 스타일 유지). `node --check`, `node scripts/validate.mjs` 통과. 커밋 금지. 마지막 메시지에 원인과 수정 내용.
